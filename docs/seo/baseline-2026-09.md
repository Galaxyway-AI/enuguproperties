## Search performance baseline

Google Search Console and Bing Webmaster Tools data was not available in the repository or connected session. The following values must be recorded from verified owner accounts, rather than estimated:

- indexed URLs;
- total organic impressions and clicks for the previous 28 days;
- branded and non-branded queries;
- average position for the tracked keyword set;
- top organic landing pages;
- Core Web Vitals field status;
- organic enquiries and seller registrations.

Do not enter zero for unavailable values. Zero would incorrectly imply that measurement occurred and no activity existed.
