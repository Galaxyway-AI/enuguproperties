## Page creation threshold

Create another indexable type/area page only when it has real search intent plus current inventory or substantial unique local guidance, relevant internal links and a useful conversion path. Otherwise retain a human-usable filtered search with noindex/follow. Do not create bedroom-count, price-band or every-area combinations automatically.

## Future expansion

The data model already supports hierarchical locations. State pages for Anambra, Imo, Abia and Ebonyi should remain unpublished until the marketplace has operational coverage, genuine inventory and useful local information in each market.
